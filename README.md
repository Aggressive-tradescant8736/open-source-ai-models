## 🔍 Understanding Key Terms

You'll see some technical words in the directory. Here's what they mean in plain English:

**Params (Parameters):** Think of this as the model's brain size. More parameters usually mean better performance, but also require more memory.

**VRAM (Video RAM):** This is memory on your graphics card. Models need enough VRAM to run smoothly. If you don't have a powerful graphics card, look for models with lower VRAM requirements.

**Context Length:** This tells you how much text the model can consider at once. Longer context means it can handle bigger documents or longer conversations.

**License:** This explains what you can legally do with the model. Some are completely free for any use, while others have restrictions like "non-commercial use only."
