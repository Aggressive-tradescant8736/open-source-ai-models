# Security Policy

This repository is a static, community-maintained directory of Markdown data — it contains no executable code, services, or dependencies of its own.

## Reporting a concern

If you find:

- A **malicious or suspicious download link** attached to a model entry
- A model entry that misrepresents its license in a way that could mislead someone into unintentional infringement
- Any other content-integrity issue

please open an issue describing the entry and the concern, or contact the maintainers directly if the report involves sensitive details you'd prefer not to post publicly.

## Out of scope

This project does not host, execute, or distribute model weights or code — it only links to official sources. Security issues in a linked model's own repository should be reported to that project directly.
